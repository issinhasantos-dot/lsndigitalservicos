# LSN Digital — Soluções Online

Projeto-base do site da **LSN Digital** preparado para versionamento no GitHub.

## Estrutura

- `index.html` — página principal
- `news/index.html` — LSN Digital News
- `assets/css/styles.css` — identidade visual e responsividade
- `assets/js/app.js` — Diagnóstico LSN em 60 segundos
- `assets/img/logo-lsn.png` — logo LSN recuperada da biblioteca

## Publicação

Este projeto é estático e pode ser aberto diretamente no navegador ou publicado em serviços como GitHub Pages, Vercel, Netlify ou outra hospedagem estática.

## Fluxo de trabalho recomendado

1. Criar uma Issue para cada correção, melhoria ou nova funcionalidade.
2. Criar uma branch a partir da `main`.
3. Implementar a alteração.
4. Fazer commit.
5. Abrir Pull Request mencionando a Issue, por exemplo: `Closes #1`.
6. Revisar e fazer merge.
7. Realizar o deploy.
